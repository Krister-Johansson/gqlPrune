# Architecture decision records

Decisions that change what gqlPrune is, not just what it does, get a short record here before implementation. Each record states the context, the options that were on the table, the decision, and its consequences, so a future reader can tell why the code looks the way it does without excavating issues and pull requests.

Format: one Markdown file per decision, numbered `NNNN-short-title.md`. Status is one of `proposed`, `accepted`, `rejected`, or `superseded by NNNN`. A record is immutable once accepted; changing course means a new record that supersedes it.
